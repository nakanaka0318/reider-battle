# RAIDER BATTLE — グレイヴ港湾区

ブラウザで遊べる 3D エクストラクション・シューター（Escape from Tarkov / ARC Raiders 系）。
装備を整えて封鎖地帯に出撃し、物資を漁って脱出地点から生還する。死ねば持ち込んだ装備はすべて失う。

- **PvPvE（オンライン）**：Node.js サーバーに接続し、他のプレイヤー＋AI レイダー＋スカブ＋ARC 機械と同じレイドで戦う
- **オール NPC モード（オフライン）**：他の「レイダー」もすべて AI。ブラウザ単体で動く PvPvE

グラフィック・アイコン・サウンドはすべてプロシージャル生成（外部アセットなし）。

## 起動方法

```bash
npm install
npm start          # ビルドしてサーバーを起動 → http://localhost:8080
```

開発時：

```bash
npm run server     # 別ターミナルで WebSocket サーバー（:8080）
npm run dev        # Vite 開発サーバー（:5173、/ws は :8080 にプロキシ）
npm run check      # データ整合性チェック＋ヘッドレスのレイドシミュレーション
```

オフラインモードだけなら `npm run build` した `dist/` を任意の静的ホスティングに置けば遊べる。
`npm run artifact` はオフライン専用の単一 HTML（`dist-artifact/raider-battle.html`）を生成する。

### サーバーの環境変数

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | 8080 | 待ち受けポート |
| `RAID_MINUTES` | 30 | レイドの制限時間 |
| `AI_RAIDERS` | 5 | オンラインレイドに混ざる AI レイダーの数 |
| `TIME_OF_DAY` | cycle | `day` / `dusk` / `night` / `cycle`（レイドごとに切替） |
| `MAX_PLAYERS` | 12 | 最大プレイヤー数 |

### スマホ（横画面）

タッチ端末では自動的にタッチ操作になる（縦向きのときは横向きにするよう案内が出る）。開始時に全画面＋横向き固定を試みる。

- 左下ドラッグ：移動スティック（前に倒し切るとダッシュ）／ 右側スワイプ：視点
- 射撃ボタン（右下・左側の 2 つ）：押したままスライドすると照準も動く
- ADS・リロード・ジャンプ・しゃがみ・リーン・武器切替・手榴弾・自動回復のボタン、対象に近づくと「漁る／拾う」ボタン
- 上部：一時停止・バッグ・マップ・脱出地点・ライト・射撃モード・倍率、下部スロットはタップで医薬品などを使用
- インベントリ：タップでメニュー（詳細・移動・使用・売却など）、ドラッグで移動、ドラッグ中にもう一本の指で「回転」
- 設定にタッチ感度。タッチ端末の初期画質は「中」
- エイムアシスト（なし／弱／標準／強、タッチ端末は初期値「標準」）：照準の近くの敵に視点が吸い付き、敵の上では感度が下がる。照準が敵に重なるとクロスヘアが赤くなる
- オートファイア（任意）：照準が敵に重なると自動で撃つ

インベントリ：ドラッグで移動、ドラッグ中 R で回転、Ctrl+クリックで素早く移動、Shift+ドラッグでスタック分割、ダブルクリックで使用・詳細。

## ゲームの内容

- **アイテム 537 種**：武器 40（ARC エネルギー兵器を含む）、弾薬 50、MOD 38、防具・ヘルメット・リグ・バックパック、医薬品・刺激剤、食料、投擲物、鍵とキーカード、バーター品 196、貴重品 48、ARC 機械パーツ 34、情報 22
- **グリッドインベントリ**：サイズ・回転・スタック・入れ子のコンテナ、装備スロット、セキュアコンテナ
- **武器カスタマイズ**：サイト（ドット〜12 倍、サーマル、暗視）、サプレッサー、グリップ、ストック、ライト／レーザー、拡張マガジン
- **ダメージモデル**：7 部位の HP、防具クラスと耐久度・貫通判定、跳弾、出血（軽・重）、骨折、部位破壊、エネルギー／水分
- **マップ**：400m 四方。軍事基地、住宅街（アパート・薬局・スーパー）、工場、無線塔、研究所、ガソリンスタンドとモーテル、港湾コンテナヤード、ARC 墜落地点。施錠された部屋と鍵、条件付き脱出（電源・料金・キーカード・ランダム）
- **AI**：スカブ（巡回・索敵・増援）、AI レイダー（POI を巡って漁り、時間が来たら脱出）、ボス「司令官グロム」と護衛、ARC 機械（ワスプ、ホーネット、自爆するティック、重装のセンチネル）
- **プレイヤー（セーブ）切り替え**：上部の 👤 から、別のプレイヤーで最初から始める・切り替える・削除する・今のプレイヤーをやり直す
- **ヒント**：高価な物が出やすい場所のマップ（金庫・施錠部屋・研究用ケースなど）、1 マス当たりの価値が高いアイテム、鍵の使い道と入手場所、稼ぎ方と生き残るコツ
- **BGM**：タイトル・メニュー・結果画面で流れるアンビエント調の曲（WebAudio で生成、レイド中は止まる）。設定で音量を変えられる
- **おまかせ装備**：倉庫画面のボタンで、空きスロットを埋める／より良い装備に入れ替える。予算を選んで、足りない装備・弾薬・医薬品をトレーダーから自動購入して編成することもできる。武器への装填、予備弾薬・医薬品・水・手榴弾の詰め込みまで自動。レイド中も拾った装備は空きスロットに自動で装着される
- **メタ**：トレーダー 5 人（売買）、ハイドアウト 7 施設（建設・強化・クラフト 39 レシピ）、タスク 14、レベルと統計、レイド履歴

## 構成

```
src/shared/   ブラウザと Node で共通のシミュレーション（three.js 非依存）
  items.js, data/       アイテム定義・ルートテーブル
  inventory.js, invops.js  グリッドインベントリ
  map.js, world.js      マップ生成・当たり判定・レイキャスト・ナビメッシュ（A*）
  combat.js             部位ダメージ・防具・状態異常
  raid.js, ai.js, bots.js  レイドのシミュレーション（ホスト権威）と AI
src/client/   描画・UI（three.js）
  game/                 レンダラー、プレイヤー操作、一人称モデル、エフェクト、サウンド、HUD
  ui/                   メニュー、インベントリ UI、トレーダー、ハイドアウト、タスク
server/server.js        静的配信 + WebSocket のレイドサーバー
```

オンラインでは移動はクライアント権威、射撃判定・ダメージ・インベントリ・AI はサーバー権威。オフラインでは同じシミュレーションがブラウザ内で動く。
